# hdp-core

Merged data-layer package for HDP primitives.

**Depth**: SKEL

- canonical: Canonical health record model + FHIR R4 bindings.
- audit: Audit batches + changes + trigger helpers.
- identity: Persons + role satellites (clinicians, patients, orgs).
- consent: Access grants + purposes + OpenFGA integration point.
- provenance: Source tracking + trust grading column pattern.
- outbox: Transactional outbox table + consumer interface.
