# HDP Vault

Obsidian vault for the Health Data Platform project. Holds design reasoning, decisions, specs, research, and patterns.

Structure:
- `adr/` — Architecture Decision Records (MADR format)
- `specs/` — phased spec-driven development artifacts
- `research/` — domain explorations and research threads
- `patterns/` — reusable design patterns (emerges over time)

Mount: this folder is a worktree of the `vault` orphan branch. On the `main` branch, `vault/` is gitignored.
